# 本地历史绘图

F407 触摸屏从本机 SD 卡读取所选节点与指标的 CSV，支持空气温度、空气湿度、光照、土壤温度、水分、电导率、pH、氮、磷、钾。四个预设的自动汇总规则与 App 1.2.5 对齐。

| 按钮 | 范围 | 自动汇总 |
| --- | --- | --- |
| 小时 | 近1小时 | 原始记录 |
| 天 | 近24小时 | 最多24条时为原始记录，超过24条按小时均值 |
| 月 | 近30天 | 有效数据首末跨度不超过24小时为原始记录；超过24小时按小时；有效小时超过72个按天 |
| 年 | 近365天 | 与月相同，有效天超过90个再按自然月 |

阈值只统计所选指标的有效记录；缺失字段不计入。等于阈值时保留较细粒度。“有效小时/天”是有记录的不同小时/日期，空白时间不占桶。

横轴左端是范围内第一条有效记录的真实时间，右端是查询结束时间。聚合点也按该桶第一条有效记录定位；点选显示首末有效时间和均值，原始点显示采集时间和数值。纵轴按实际显示值缩放。

“原始记录”指 SD 保存的每个采集窗口的一份记录。当前每15分钟开始一个5分钟窗口，保存窗口平均值；本功能不会制造新的5秒原始传感器记录。

## 时间与操作

取得有效设备时间后，默认范围按当前分钟定位，结束为下一分钟起点，查询不包含结束时间。开机4G查询网络时间后即可更新，无需等待首次数据上传。未取得有效时间时，以 SD 最新记录定位。新记录或分钟推进触发查询，界面局部刷新。

点击指标名可切换指标；概览和土壤的数据框可直接打开对应的近一小时图。“上一段/下一段”产生固定范围，“刷新”重查该范围，读取时可以取消；退出历史也停止查询。

“选时段”保留固定小时/天/月粒度。取得时间后，开始和结束均不得晚于当前时间；无效增减操作置灰，结束必须晚于开始。自选范围不随当前时钟移动。

## 存储与容量

主节点按 `data/air`、`data/light`、`data/soil` 分类保存；其他节点使用各自的 `nodes/nodeXXXX/data` 目录，兼容早期合并 CSV。历史读取器只读，不格式化或迁移已有数据。

原始缓存最多512条，覆盖每小时20条、一天约480条的场景。异常高频文件超过512条时完整重读并改为小时均值，底部显示实际粒度，不截取前512条。固定自选粒度最多96个连续桶，过长时合并相邻桶。

预设查询先统计有效跨度与小时/天占用；仅需汇总时做第二轮读取。查询按32项/约8ms软预算分批推进，单次底层 SD I/O 可能超过预算。无卡、无数据、格式错误和读卡错误分别显示提示。

`HistorySeries.points` 已改为16位，新增字段使旧内存结构偏移失效；调试工具应使用对应构建的符号与结构，不能套用旧偏移。
