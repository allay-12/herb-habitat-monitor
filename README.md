# Herb Habitat Monitor

使用 STM32F407VET6、土壤探头和百叶箱模块监测药材生长环境，支持本地触摸屏查看、SD 卡存储及 Air780E 4G 上传，手机应用通过服务器查看数据。

上电后开始采集，每15分钟开启传感器5分钟，前30秒等待传感器启动，随后轮询。每轮生成一份有效样本平均值，保存到 SD 卡并排队上传，剩余10分钟休息；断网记录保留在 SD 卡待传队列，网络恢复后补传。

## 引脚连接说明

**接线前请先看 [PIN_CONNECTIONS.txt](docs/PIN_CONNECTIONS.txt)。** 文件包含34针屏幕逐针对应、触摸、板载 SD、Air780E、RS485、传感器、MOS 和 SWD 接线，也标明当前启用与预留接口。

- 百叶箱地址2、土壤地址1，共用4800/8N1及同一条 RS485 总线。
- 本项目所用 Air780E 转接板：PA2 接板端 TXD，PA3 接板端 RXD；此板端命名对应仅适用于已核对的同款载板。
- PB0 控制传感器供电；PB1 目前保持低电平，4G 使用独立常供5V。
- PA1、PB8/PB9 继续预留，暂未启用 PWRKEY 控制或 INA219 电源监测。
